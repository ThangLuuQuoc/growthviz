# BotanicaSim — Fruit Tree & Flowering Plant Growth Simulator

Interactive biological life cycle and ontogenetic growth simulator for fruit trees (**Apple**, **Mango**, **Orange**) and flowering plants (**Crimson Rose**, **Giant Sunflower**, **Moth Orchid**).

## Tech Stack
- **Frontend:** React 18, TypeScript, Vite, Tailwind CSS, Lucide Icons
- **State Management:** Zustand
- **Rendering:** Real-time HTML5 2D Procedural Fractal / L-System Botanical Canvas

## Getting Started

```bash
npm install
npm run dev
```
